# GlyphDraw for Nothing Phone (4a) Pro

A simple Android application that allows you to draw patterns on a 13x13 grid and display them on the back Glyph Matrix of your Nothing Phone (4a) Pro.

## Features
- 13x13 interactive drawing grid.
- Real-time updates to the Glyph Matrix.
- Clear button to reset the pattern.
- AOD (Always On Display) support.

## How to use
1. Install `build_output/GlyphDraw.apk` on your Nothing Phone (4a) Pro.
2. Open the app.
3. Tap on the grid cells to toggle LEDs.
4. Watch the pattern appear on the back of your phone!

## Development
Built using the Nothing Glyph Matrix SDK. Requires compileSdk 34 and minSdk 33.
